#/skill:technical-documentation

Review the current WorldGL repository and prepare its documentation for public readers.

1. Inspect the implementation, tests, README and existing docs.
2. Rewrite README.md to approximately 50–80 lines: purpose, current capabilities, quickstart and links to detailed docs.
3. Move useful technical details into docs/ without losing information.
4. Clearly distinguish implemented features, observed results and future hypotheses.
5. Propose a structure for a chronological engineering journal, but do not write the journal entries yet.

Do not change application code. Do not invent capabilities or experimental results. Do not commit or push.

Make the documentation changes and summarize them for human review.
