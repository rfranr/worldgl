Review WorldGL's README, docs and implemented UI to propose a screenshot and visual documentation plan.

For each proposed screenshot, specify:
- Which feature or behavior it should demonstrate.
- The exact documentation file and section where it belongs.
- Suggested filename under docs/assets/.
- What should be visible in the screenshot.
- Suggested Markdown caption and alt text.

Prioritize a compelling world overview in the README, then the experiment inspector, navigation/trajectory visualization and multi-run comparison where useful.

Keep the number of images small. Avoid decorative or redundant screenshots.
Base recommendations on features actually implemented, not planned capabilities.

Do not capture or generate images yet. Do not modify files, commit or push.
